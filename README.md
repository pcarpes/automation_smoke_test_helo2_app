
# Helo² Smoke Test Automation

This repository contains an **end‑to‑end smoke‑testing harness for the Helo² (staging) web application** used by three customers:

* **Owens & Minor**  (`owens`)
* **Recreational Equipment Inc.** (`recreational`)
* **Parker Hannifin** (`parker`)

The tool logs in to the Helo² staging site, drills down into each customer environment, opens a curated list of pages, captures their record counts, and writes the results back to Excel so product teams can spot regressions at a glance. All logic lives in a single Jupyter notebook (`helo2_smoke_test.ipynb`).

## Key functionalities & design

### High‑level flow

1. **Launch Chrome** with Selenium WebDriver (`open_chrome`).
2. **Navigate to the Helo staging URL** (`open_helo_webpage`).
3. **Log in** with credentials from `config.py` (`login`).
4. **Switch to the desired customer** (`choose_customer`).
5. **Toggle to the Helo² interface** (`change_to_helo2`).
6. **Load the customer‑specific test plan** from Excel (`read_customer_smoke_test_file`).
7. **Add a new results column** stamped with today’s date (`insert_date_column`).
8. **Iterate over every link**, capture the record count, and compute the delta from the baseline (`smoke_test`).
9. **Persist the interim DataFrame** for that customer (`save_customer_test`).
10. **Close the browser** and repeat for the next customer (`close_chrome`).
11. **Write the three DataFrames** to `helo2_smoke_test_python.xlsx`, one sheet per customer (`save_excel_file`).
12. A convenience wrapper, `run_smoke_test`, executes the full cycle for all customers ([github.com](https://github.com/pcarpes/automation_smoke_test_helo2_app/raw/main/helo2_smoke_test.ipynb)).

### Function map

| Function | What it does |
|----------|--------------|
| `open_chrome()` | Starts a local ChromeDriver session. |
| `open_helo_webpage(driver)` | Opens the staging URL with a deep link that pre‑loads grid filters. |
| `login(driver)` | Fills **Email** and **Password** fields and clicks **Log in**. |
| `choose_customer(driver, customer)` | Uses the React Select search box to change the client tenant. |
| `change_to_helo2(driver)` | Opens the version picker and enables the Helo² toggle. |
| `read_customer_smoke_test_file(customer)` | Reads the relevant sheet (Owens = 0, Recreational = 1, Parker = 2) from `HELO2 ‑ SMOKE TEST.xlsx`. |
| `insert_date_column(df)` | Inserts a new column (index 3) headed with `YYYY‑MM‑DD`. |
| `smoke_test(df)` | Visits every URL in the **HELO2 ‑ Staging Link** column, waits for the AG‑Grid loader to disappear, scrapes the first counter badge, records it, and calculates the delta. |
| `save_customer_test(customer, df)` | Stores the in‑memory DataFrame for later consolidation. |
| `close_chrome(customer)` | Prints completion banner and closes the Chrome window. |
| `smoke_test_by_customer(customer)` | Orchestrates the above steps for a single customer. |
| `save_excel_file()` | Writes all three customer result sets to **one** workbook: <br>`O&M - SMOKE TEST`, `REI - SMOKE TEST`, `PH - SMOKE TEST`. |
| `run_smoke_test()` | Executes `smoke_test_by_customer` for every customer in `customer_list`. |

## Getting started

```bash
# 1  Clone
$ git clone https://github.com/pcarpes/automation_smoke_test_helo2_app.git
$ cd automation_smoke_test_helo2_app

# 2  Add credentials
$ cp config.py config.local.py   # keep secrets out of Git
# edit config.local.py and set username/password

# 3  Install deps & launch notebook (optional)
$ pip install -r requirements.txt  # or use the one‑liner above
$ jupyter lab helo2_smoke_test.ipynb
# run ▶️ all cells

# OR run headless from CLI:
$ jupyter nbconvert --to python helo2_smoke_test.ipynb
$ python helo2_smoke_test.py
```

The script will open Chrome **visibly** (no headless flag is set), cycle through the three customers, and write **`helo2_smoke_test_python.xlsx`** in the project root.

---
## Customisation tips

* **Run a subset of customers** – edit `customer_list` inside `run_smoke_test()`.
* **Add a new customer** – create a new sheet in the input workbook *and* extend the `read_customer_smoke_test_file()` `if`/`elif` chain.
* **Headless execution** – change `webdriver.Chrome()` to `webdriver.Chrome(options=opts)` with `opts.add_argument('--headless=new')`.
* **Timeouts** – adjust `time.sleep(...)` calls or switch to Selenium’s explicit waits for robustness.

---
## Caveats & future work

* **Hard‑coded waits** – swap `time.sleep` polling with `WebDriverWait` for faster, more reliable runs.
* **Credentials in code** – consider environment variables or a secrets manager.
* **Continuous delivery** – a GitHub Actions workflow could run the smoke test on every staging deploy and attach the Excel report as an artifact.
